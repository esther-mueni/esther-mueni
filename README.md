# Hi, I'm Esther Mueni 👋

Product Manager · Vibe Coder · Writer

I love building solutions and telling stories. I started as an embedded systems engineer working on IoT gadgets, transitioned into product management, and now work as a product manager with strong vibe coding skills — using them to exercise my problem-solving muscle and build real systems.

Right now, I'm building systems for **Attic Chapter**, a youth entrepreneurship community, and occasionally ship hobby projects to flex my vibe coding skills. When my credits run out, I write — on LinkedIn or Substack — about product, tech, and building in African markets.
